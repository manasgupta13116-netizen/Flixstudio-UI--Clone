FlixStudio
🎬 Netflix UI Clone A pixel-perfect clone of the FlixStudio Home & Landing Page, built entirely from scratch using pure HTML5 and CSS3.

This project was developed to practice semantic HTML, modern CSS layouts (Flexbox and Grid), and responsive web design principles without relying on external UI frameworks like Bootstrap or Tailwind.

🚀 Live Demo 🔗

✨ Features Pixel-Perfect UI: Closely mimics the actual Netflix landing page layout, color palette, and typography.

Fully Responsive: Optimized for desktop, tablet, and mobile screens using CSS Media Queries.

Interactive Components: Features working hover states, styled buttons, and smooth transitions.

Accordion FAQs: A dedicated, CSS-styled Frequently Asked Questions section.

No Frameworks: 100% vanilla HTML and CSS for lightweight, fast-loading performance.
